FastAPI Microservice Integration

Live endpoint specification for containerized inference and microservice orchestration.

POST /predict
curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "store_id": "CA_1",
    "item_id": "FOODS_3_090",
    "horizon": 28,
    "model": "LightGBM"
  }'
Python Client
import requests

res = requests.post(
    "http://localhost:8000/predict",
    json={"store_id": "CA_1", "item_id": "FOODS_3_090", "horizon": 28, "model": "LightGBM"}
)
forecast = res.json()
print("Mean 28-day forecast:", forecast["mean_forecast"])
